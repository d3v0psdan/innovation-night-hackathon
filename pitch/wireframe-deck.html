09 The decision logicref: Hootsuite compare, plain data table
Rules, not a black box
First match lands. Every match queues.
  • Stage rules run first: no idea yet or pivoting means the Journey map, whatever the goals
  • Each goal adds its tool to the list, no duplicates
  • No match: the dashboard, said honestly
  • Every rule has a test
