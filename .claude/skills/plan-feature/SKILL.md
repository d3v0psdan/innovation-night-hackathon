# Plan the feature

1. Read `CONTEXT.md` first. If it doesn't exist, run the context skill before anything else.
2. Write the plan to `PLAN.md` with these sections, max 30 lines total
   - **Users** 2 or 3 user types the onboarding should tell apart
   - **Questions** 3 or 4 questions max, each with fixed answer options
   - **Routing** which answers send which user type where
   - **Screens** list of pages to build
   - **Cut list** what we're NOT doing tonight
   - **Demo story** two users, two different journeys, in 4 sentences
3. Check the plan against the judging criteria. Flag anything missed.
4. Stop and ask Daniel to approve before any code.

Rules
- If it can't be built in about 2 hours, cut it
- Fixed answer options only. No free text that needs AI to interpret unless the challenge asks for it
