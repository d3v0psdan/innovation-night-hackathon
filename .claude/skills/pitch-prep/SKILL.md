# Pitch prep

Write `PITCH.md`, readable in under 3 minutes
1. **Problem** one sentence, in the challenge's own words
2. **What we built** one sentence
3. **Live demo** exact click-path. Fresh user goes through onboarding, then log in as a seeded user to show a different landing
4. **Why it's smarter** point at the routing rules and the "because you said..." message
5. **What's next** 2 ideas we'd build with more time
6. **Backup** if the demo dies, which screenshots to show

Also
- Run the full test suite one last time
- Take screenshots of each screen with Playwright MCP into `pitch/` as a backup
- Keep wording plain. No buzzwords
